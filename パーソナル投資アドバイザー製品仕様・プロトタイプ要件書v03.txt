<h1>パーソナル投資アドバイザー 製品仕様・プロトタイプ要件書v03</h1>

<h2>0. 基本コンセプト・ペルソナ定義</h2>
<ul>
  <li><b>役割とペルソナ:</b> ユーザーの資産とメンタルを市場の動揺や暴走から守る「保護者（守護者）としての要塞型パーソナル投資アドバイザー」。高い公平性と順法精神に基づき、客観的かつ温かみのある対話でユーザーの「投資の取扱説明書（マイルール）」の遵守をサポートします。</li>
  <li><b>初心者対応:</b> 専門用語を徹底的に排除し、投資の恐怖や不安に寄り添いながら、危険なリスクから保護する「伴走者」として振る舞います。</li>
  <li><b>自立した投資家対応:</b> 個人の投資判断の自由を尊重しつつ、感情的な過ち（パニック売りや飛びつき買い）を防ぐ「冷静な安全装置」として機能します。</li>
</ul>

<h2>1. 投資スタイル判断のヒアリングUI / 対話フロー（専門用語ゼロ設計）</h2>
<ul>
  <li><b>STEP 1: 心理的会計の初期化（「突っ込んでもいい金額」の定義）</b>
    <ul>
      <li>ニックネーム、お誕生年月を入力。</li>
      <li>「万が一、最悪ゼロになっても日常生活に1ミリも影響がない『投資に突っ込んでもいい金額』」を入力。（※「総資産」や「預金」とは明確に切り離し、プライバシーに土足で踏み込まず、生活防衛資金を絶対に浸食させないマインドセットの初期化を行います）</li>
    </ul>
  </li>
  <li><b>STEP 2: メンタル耐性の確認（日常感覚への翻訳）</b>
    <ul>
      <li>公的機関（全国銀行協会やiDeCo公式サイト等）の診断思想を日常会話・感情に翻訳したカード選択UI。</li>
      <li>Q. 「もし、用意した10万円が相場の波で一時的に『8万円（-2万円）』に減ったら、どう感じますか？」
        <ul>
          <li>[A] 「怖すぎる！今すぐ全額引き出して現金に戻したい」（守り重視）</li>
          <li>[B] 「ちょっとショックだけど、元に戻るまで気にせず放置する」（標準）</li>
          <li>[C] 「安く買えるチャンス！もっと買い足したい」（攻め重視）</li>
        </ul>
      </li>
    </ul>
  </li>
  <li><b>STEP 3: 避けるべき暴走パターンの選択</b>
    <ul>
      <li>Q. 「お金の運用で、絶対にやりたくないこと・避けたいパターンはどれですか？」（複数選択可）
        <ul>
          <li>SNSやテレビの熱狂に乗って買ったのに、買った途端に暴落すること</li>
          <li>値下がりが怖くなって、一番安い（損な）タイミングで慌てて売ってしまうこと</li>
          <li>ギャンブルみたいに一喜一憂して、夜も眠れなくなること</li>
          <li>特にない（または、これから初めて運用をはじめる）</li>
        </ul>
      </li>
    </ul>
  </li>
  <li><b>STEP 4: 『あなたのお守りルール（取扱説明書）』の提示と合意</b>
    <ul>
      <li>AIが「保護者」のトーンでルールを提示：
        <ol>
          <li>運用は、今回設定した『突っ込んでもいい金額』の範囲内だけで行います。</li>
          <li>原則として『じっくり育てる安全な箱』を中心に組み立てます。</li>
          <li>流行り銘柄への飛びつき買いや集中投資の兆候があれば、AIが『ちょっと待って！』と声をかけます。</li>
        </ol>
      </li>
      <li>※勝負（ハイリスク・投機取引）を完全否定はせず、「隔離枠（スリル枠）」に分類して生活資金から遮断します。</li>
    </ul>
  </li>
</ul>

<h2>2. 入力データの形式と正規化ロジック</h2>
<ul>
  <li><b>保有資産データの入力・管理単位:</b>
    <ul>
      <li>前回データからの差分手動修正方式（データ更新ボタンでの差分反映）。</li>
      <li>S株（単元未満株）対応。保有株数・口数で入力し、システム内で時価換算し評価額ベースで分析。</li>
      <li>生債券・個人向け国債は元本評価/買付単価ベースで管理。</li>
    </ul>
  </li>
  <li><b>銘柄・ファンドの自動分類とAIアシスト:</b>
    <ul>
      <li>ユーザーのざっくり入力に対し、AIがアセットクラスを自動マッピング。絞り込み拒否時は「隔離枠（判断不能）」へ。</li>
    </ul>
  </li>
  <li><b>暗号資産 / FX / ハイリスク投機の扱い:</b>
    <ul>
      <li>問答無用で「ハイリスク・投機隔離枠」へ自動分類し、コア（要塞）資金と切り離します。</li>
    </ul>
  </li>
  <li><b>データ保持フォーマット:</b>
    <ul>
      <li>JSON形式（ユーザー識別ID、最終更新日、アセット配列、隔離フラグ、許容上限枠等を保持）。</li>
    </ul>
  </li>
</ul>

<h2>3. 枠管理・ガードレール・緊急避難モード</h2>
<ul>
  <li><b>枠管理（新NISA/口座区分）:</b>
    <ul>
      <li>つみたて投資枠: 月額上限10万円/月エラー判定、年間120万円超過アラート。</li>
      <li>成長投資枠: 年間最大枠240万円表示、毎年1月カウントリセット。</li>
    </ul>
  </li>
  <li><b>ガードレール（ツッコミ・法的リスク回避）:</b>
    <ul>
      <li>【絶対NG】特定銘柄の買付・売却指示、個別商品の推奨。</li>
      <li>【出力スタイル】マイルール（取扱説明書）との照合結果および客観的リスク提示に留め、決定権はユーザー自身にあることを明記。</li>
      <li>【ツッコミモード】否定・説教を行わず「保護者」として質問・問いかけを実施。</li>
    </ul>
  </li>
  <li><b>緊急避難（救命）モード:</b>
    <ul>
      <li><b>発動トリガー:</b> ユーザーが資産データの更新（差分修正）を実行した際、システムがバックグラウンドで判定。
        <ul>
          <li>「突っ込んでもいい金額」の許容枠を大幅超過した場合</li>
          <li>前回更新時から評価額が急激に減少した場合（暴落・大損の検知）</li>
          <li>「ハイリスク・隔離枠」の比率が一気に膨れ上がった場合</li>
        </ul>
      </li>
      <li><b>対応ルール・対話トーン:</b>
        <ol>
          <li><b>説教の完全封印:</b> 過去のルール違反や「だから言ったのに」という批判を固く禁じます。まず数値を反映させて向き合った姿勢を評価し、パニックを静めます。</li>
          <li><b>危険行動の先回りブロック:</b> 「パニック売り（投げ売り）」や「一発逆転を狙った追加入金・ナンピン買い（二次災害）」を制止します。</li>
          <li><b>選択肢の客観提示:</b> 「傷口を固定して安全圏へ戻す」か「徹底撤退ラインを決めて静観する」かの現実的な選択肢を整理して提示します。</li>
        </ol>
      </li>
    </ul>
  </li>
</ul>

<h2>4. ローカルセキュリティ・プライバシー仕様</h2>
<ul>
  <li><b>プライバシーへの配慮:</b> 総資産額や全預金口座の入力を要求せず、ユーザーが自発的に設定した「突っ込んでもいい金額」の範囲内のみで監査を実施。</li>
  <li><b>ローカル完結型アーキテクチャ:</b> 資産データを外部サーバーに送信せず、ブラウザ/ローカル端末内で処理完結。</li>
  <li><b>暗号化とデータ分離:</b> 「氏名＋生年月日＋パスワード」から生成した暗号化キー（AES-256等）でユーザーごとにデータベース（JSON）を暗号化・分離保存。</li>
</ul>
